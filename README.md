# Data Analyst Jobs Analysis 
**1. Project Title :**
                   Data Analyst Jobs Analysis  - This Project gives insights about various data roles mainly in the US.

****2. Description :**
     - The EDA explains that data analysis have a lot of job requirements/postings compared to any other data roles in the US .
     - It says  the skills required for data analysis roles.
     - It also gives insights about the most demand skills and also the most paying skills for data analysis.
     - It also explains the number of data analyst job listings across the world.

**3. Tech Stack :**     

        The visualisations was built using the following tools
      📈 - Data tranforming, Cleaning and Visualization using pandas,matplolib and seaborn libraries.
 
**4. Data Source :** 

      Source : The dataset  has been taken from the "github" platform which was under "cc Public Domain".

**5. Higlights/Insights :**

     The chart suggests that the most valuable technical skills for data analysts are:
      1) Python,SQL and Tableau
      2) Top paying skills for a data analyst includes dplyr,bitbucket and  Gitlab based on the median salaries
      3) Most required skills for the data analyst roles in the US includes Python, Tableau and R, SQL Server and SQL.
      4) Most of the job postings have been posted in the month of January.
